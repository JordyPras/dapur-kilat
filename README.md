A fast-paced Indonesian warung cooking game, built for the [Make the best cooking game](https://make.fun/bounty/best-cooking-game-20261125-0137) bounty on make.fun. Tickets arrive on the order board with a patience timer; you run the cook around the kitchen — grab rice, noodles, chicken, greens, egg and chili from the pantry, chop on the board, fry on the wok, grill satay, pour iced tea — then plate and serve before patience runs out. Consecutive on-time serves build a combo, each day brings faster tickets and shorter patience, and three missed orders end the service. All art is drawn on canvas and all sounds are synthesised with WebAudio; the game is plain static files with no build step and no network requests.

Menu: Nasi Goreng (rice + egg + chopped chili, wok), Mie Ayam (noodles + chopped chicken + chopped greens, wok), Sate Ayam (skewers + peanut sauce, grill), Es Teh (tea + ice, kettle).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with mouse and keyboard: click stations to walk the cook there, keys 1–4 select a ticket, Space chops and cooks, P pauses, M mutes.
